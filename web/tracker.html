Position Tracker

Tempel alamat Cardano kamu untuk melihat posisimu di semua vault Strike. Tanpa login, tanpa kunci, murni dari data publik.

Alamat Cardano

Alamat dinormalisasi otomatis (spasi dibuang, huruf kecil). Gunakan alamat pembayaran (addr1...), bukan alamat stake (stake1...).
Batasan apa adanya: data posisi berasal dari snapshot depositors publik Strike (diperbarui tiap jam oleh EarnScope). Line Borrow to Earn per akun dan status staking resmi TIDAK bisa dilacak publik karena berada di balik autentikasi Strike. Saldo STRIKE on-chain diambil langsung dari Koios dan bisa gagal dimuat bila jaringan Koios lambat.
Sumber: API publik Strike (api.strikefinance.org) + Koios (api.koios.rest) · Dibangun untuk Strike 48h Hackathon
