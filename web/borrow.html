Simulator Borrow to Earn

Skema resmi Strike: kunci jaminan (mis. ADA), terima kredit USD bunga 0%, kredit wajib masuk vault SLP. Simulator ini memakai data asli: harga ADA live dari API pasar Strike dan kinerja SLP historis dari tracker EarnScope.

1. Mekanisme

  1. Kunci jaminan, mis. ADA senilai C USD.
  2. Tarik kredit USD sebesar % draw dari C, bunga 0%.
  3. Kredit wajib disalurkan ke vault Strike Liquidity Provider (SLP).
  4. Hasil bersih = nilai kredit di SLP pada akhir horizon − pokok kredit.
  5. Kesehatan line = ekuitas jaminan akhir ÷ pokok kredit.

Strike tidak mempublikasikan batas draw maksimum resmi; 50% dipakai sebagai contoh umum.
